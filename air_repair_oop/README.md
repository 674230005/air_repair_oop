# AirCare — ระบบแจ้งซ่อมแอร์ด้วย PHP OOP / OOAD และ MySQL

## ความสามารถ
- เข้าสู่ระบบและออกจากระบบ
- บทบาทแอดมิน ผู้ใช้ และช่าง
- ผู้ใช้แจ้งซ่อมและแนบภาพ JPG/PNG/WEBP ได้ไม่เกิน 5 MB
- แอดมินและช่างดูรายการทั้งหมดและเปลี่ยนสถานะได้
- ข้อมูลคำขอและบัญชีเก็บใน MySQL; ไฟล์ภาพเก็บใน `uploads` และบันทึก path ลง SQL
- ธีมเหลือง-ดำ รองรับมือถือ
- มีคอมเมนต์ภาษาไทยอธิบายโค้ด PHP และไฟล์ SQL

## ติดตั้งบน XAMPP
1. แตก ZIP แล้วนำโฟลเดอร์ `air_repair_oop` ไปไว้ที่ `C:\xampp\htdocs\`
2. เปิด XAMPP Control Panel แล้วกด Start ที่ **Apache** และ **MySQL**
3. เปิด `http://localhost/phpmyadmin/`
4. เลือกแท็บ **Import** แล้วเลือกไฟล์ `database/air_repair_db.sql` จากโฟลเดอร์โปรเจกต์ จากนั้นกด Import/Go
5. ตรวจสอบค่าเชื่อมต่อใน `config/database.php` หาก MySQL ของคุณมีรหัสผ่าน ให้แก้ตัวแปร `$password`
6. เปิด `http://localhost/air_repair_oop/install.php` เพื่อสร้างบัญชีทดลอง
7. หลังขึ้นข้อความติดตั้งสำเร็จ ให้ลบ `install.php` เพื่อความปลอดภัย
8. เปิด `http://localhost/air_repair_oop/`

## บัญชีทดลอง
- แอดมิน: `admin` / `admin123`
- ผู้ใช้: `user` / `user123`
- ช่าง: `tech` / `tech123`

## แนวคิด OOP
- `Database`: จัดการการเชื่อมต่อฐานข้อมูล
- `Auth`: ตรวจสอบบัญชีผู้ใช้และสิทธิ์
- `RepairRequest`: จัดการคำขอแจ้งซ่อม เพิ่ม ค้นหา และแก้ไข
- Encapsulation: ซ่อนรายละเอียดการเชื่อมต่อและการจัดการข้อมูลไว้ในคลาส
- Abstraction: หน้าเว็บเรียกใช้เมธอดของคลาส แทนการเขียน SQL ซ้ำในทุกหน้า

## แนวคิด OOAD
- Actor: แอดมิน ผู้ใช้ ช่าง
- Use case: Login, แจ้งซ่อม, แนบรูป, ดูรายการ, อัปเดตสถานะ, Logout
- ตารางฐานข้อมูล: `users`, `repair_requests`

## หมายเหตุ
โครงการนี้เป็นตัวอย่างเพื่อการเรียนรู้ ควรเพิ่ม CSRF protection, การจัดการบัญชีจริง และมาตรการสำรองข้อมูลก่อนใช้งานจริง


## เพิ่มระบบมอบหมายงานให้ช่างในฐานข้อมูลเดิม
- หากติดตั้งฐานข้อมูลไว้แล้ว ให้เปิด phpMyAdmin เลือก `air_repair_db` แล้ว Import ไฟล์ `database/upgrade_assignment.sql` เพียงครั้งเดียว
- ไฟล์นี้เพิ่มคอลัมน์ช่างผู้รับผิดชอบและสถานะ `มอบหมายแล้ว` โดยไม่ลบข้อมูลเดิม
- เข้าระบบด้วยแอดมิน แล้วเลือกช่างจากคอลัมน์ `มอบหมายช่าง` ในแดชบอร์ด
- ช่างจะเห็นเฉพาะรายการที่แอดมินมอบหมายให้ และแก้ไขได้เฉพาะงานของตน
- ถ้าเป็นการสร้างฐานข้อมูลใหม่ตั้งแต่ต้น ให้ใช้ `database/air_repair_db.sql` เวอร์ชันปัจจุบันแทนไฟล์ upgrade
